TRACE WIDTH FORMULA (IPC-2221A)
================================================================================

External Layers:  I = 0.048 × ΔT^0.44 × A^0.725
Internal Layers:  I = 0.024 × ΔT^0.44 × A^0.725

Where: I = Current (A), ΔT = Temp rise (°C), A = Area (mils²)
Rearranged: A = (I / (k × ΔT^0.44))^(1/0.725)
Width (mils) = Area / Copper thickness (mils)

PRACTICAL DESIGN TIPS
================================================================================

1. LED_5V traces (160 mils) are VERY wide
   → Option 1: Use 2oz copper to reduce to ~80 mils
   → Option 2: Route on multiple layers/parallel traces
   → Option 3: Use wide traces as shown (safe, conservative)

2. Keep VBUS_USB_5V isolated from LED_5V
   → Different voltage domains (though same voltage!)
   → Prevent noise coupling into USB supply
   → Use ground planes and layer separation

3. 3.3V digital signals can use tighter spacing (3 mil)
   → Lower voltage allows closer traces
   → Reduces board area requirements
   → Still meets Class 2A standards

4. Use ground plane for:
   → Return paths for all signals
   → Thermal distribution for power components
   → EMI shielding between signal domains
   → Improves trace carrying capacity

5. Via sizing for K1:
   → Standard 10 mil diameter via
   → 1 mil copper plating (Class 2 minimum)
   → Stitching vias for ground plane continuity

PYTHON LIBRARY QUICK START
================================================================================

# Calculate trace width
from ipc_standards_library import IPC2221A, TemperatureRise

width, area = IPC2221A.calculate_trace_width(
    current_ma=8000,
    temp_rise=TemperatureRise.POWER_EXTERNAL,
    is_external=True,
    copper_oz=1.0
)
width_standard = IPC2221A.round_trace_width(width)

# Get K1 recommendation
from ipc_standards_library import K1Configuration

width = K1Configuration.get_recommended_trace_width('LED_5V')
clearances = K1Configuration.get_clearance_for_domain('VBUS_USB_5V')

# Validate design
from ipc_standards_library import validate_design

valid, message = validate_design(160.0, 4.0, 5.0)

# Generate report
from ipc_standards_library import IPCReporter

report = IPCReporter.generate_pcb_design_report("K1 Lightwave")
